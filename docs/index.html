Pourquoi rbak

Un outil de backup pensé pour les serveurs applicatifs.

Configure une fois, lance à la demande ou sur un planning, et garde les archives hors du serveur.

⚙️

Configuration YAML

Plusieurs modèles dans un seul fichier, avec valeurs par défaut et messages d’erreur lisibles.

🗄️

Dumps MySQL

Exécution via le client natif mysqldump, avec sortie SQL dédiée par base.

🧹

Workdir propre

Dossier temporaire configurable, avec un sous-dossier par modèle et nettoyage automatique même en cas d’échec.

📦

Archives à venir

Inclusion de fichiers, tar, compression tgz/tbz2/txz, puis split.

☁️

Stockages prévus

Local, FTP, SFTP, SCP, S3, MinIO, WebDAV et autres destinations cloud au fil des versions.

🔔

Notifications

Webhook, Slack, Discord, mail et Telegram sont prévus après le pipeline de backup complet.

Pipeline cible

Du dump brut à l’archive externalisée.

Aujourd’hui rbak couvre le dump MySQL et le cleanup. Le reste arrive par étapes verticales.

  1. Dump databases implémenté
  2. Collect files prochaine étape
  3. Create archive tar
  4. Compress tgz / tbz2 / txz
  5. Encrypt age
  6. Split chunks
  7. Upload local / cloud
  8. Rotate retention

Configuration

Un modèle = une unité de backup.

rbak lit ~/.rbak/rbak.yml par défaut, ou le chemin passé avec -c/--config. Chaque modèle peut contenir plusieurs databases.

  • CLI : rbak perform
  • Chemin explicite : rbak perform -c ./rbak.yml
  • Workdir configurable pour les fichiers temporaires
workdir: /tmp

models:
  my_site:
    databases:
      primary:
        type: mysql
        host: localhost
        port: 3306
        database: myapp_prod
        username: root
        password: s3cr3t

Roadmap

Petit binaire maintenant, pipeline complet demain.

Le projet avance par versions : d’abord le MVP CLI, puis les stockages, la sécurité et l’automatisation.

v0.1

CLI, YAML, MySQL

Base actuelle : parser de config, sous-commande perform, dumps MySQL et pipeline par modèle.

v0.2

Archives et stockages

Tar, compression, stockage local, FTP, SFTP, SCP, S3/MinIO et WebDAV.

v0.3–0.5

Chiffrement, daemon, notifications

Chiffrement age, découpage, rétention, scheduler intégré et notifiers success/failure.

v1.0

Databases et polish

PostgreSQL, Redis, MongoDB, SQLite, MariaDB, MSSQL, InfluxDB, etcd, Firebird et documentation complète.
